# 密式旅行設計指南

這份文件是網站視覺與介面語意的單一參考來源。它描述「如何呈現既有內容」，不取代房價、訂房、退款、寵物、訪客、餐點、入住退房、聯絡或匯款規則的正式內容來源。

## 設計方向

網站採用 **Dusk Mountain Editorial**：像一本在山裡慢慢翻閱的旅行誌。深夜藍 `#242943` 是畫布，米白 `#f5f0e6` 是主要文字，低飽和 aqua `#9dd8d0` 用於行動與導覽狀態，champagne `#d9b98c` 用於細線、編號與小幅強調。留白、細線、圖片裁切與不對稱留邊帶出山景的安靜感。

## 色彩與字型

- 全站字型使用既有的 `/fonts/setofont.woff2`，透過 `--font-heading` 與 `--font-body` 共用。
- 全站固定深色，不跟隨作業系統切換淺色。背景 `#242943`、卡片／須知面板 `#2a2f4a`；米白 `#f5f0e6` 是文字，不是閱讀區或卡片大底。水綠用於主要操作，香檳色只用於小面積提示。
- 不引入 Google Fonts、外部字型、額外 UI 套件或新的圖片素材。
- 新增繁體中文前，先檢查既有字型涵蓋率；發現缺字時回報並測試，不替換或重製字型檔。原檔的「鄉」（U+9109）與「閱」（U+95B1）具有空輪廓，本版僅以 CSS unicode-range 排除這兩個碼位，讓既有 sans-serif fallback 顯示原文；其他碼位與原字型檔完全不變。

## 內容、呈現與 metadata 的界線

頁面上的文案、房價、規則與聯絡資料屬於公開內容，必須保留正式來源的原文與層級。CSS、版面、圖片 `alt`、尺寸、`loading` 和 `fetchpriority` 是呈現或效能 metadata，可以在不改變事實的前提下改善。

`title`、`description`、canonical、Open Graph、JSON-LD 與圖片 alt 是搜尋與無障礙 metadata；它們應描述同一個既有事實，不能捏造價格、服務承諾、地址細節或訂房流程。圖片 alt 說明照片中可辨識的場景，不把關鍵字堆進去。

原始素材與商業規則是保護項目：不要替換 `public/images/` 既有圖片、不要改 `public/fonts/setofont.woff2`、不要變更房價或訂房相關內容，除非需求明確授權。首頁六張導覽 tile 的中文名稱、連結與行動文案視為既有內容。

## 頁面語意

- 每頁維持一個主要 `h1`。首頁 hero 的中文品牌名稱是 `h1`，英文品牌字樣只是同一標題中的較小呈現。
- 房型列表用住宿類別 `h2`（露營營位、露營木屋、套房），類別下的房型卡使用 `h3`；不要以視覺大小取代 heading 階層。
- 首頁導覽區以區塊標題 `h2`，六張 tile 延續既有首頁測試契約使用 `h2`，連結本身是整張卡片的主要互動目標。
- 主要內容放在唯一的 `<main id="main">`，skip link 必須能到達它。

## 圖片與效能

首頁 hero 使用既有 `/images/banner.webp` 原生 `<img>`，保留實際尺寸 `1478x1108`、`loading="eager"`、`fetchpriority="high"` 與描述性 alt；`<head>` 的 image preload 必須指向同一個路徑。其他首頁 tile 圖片應使用既有素材，具備尺寸、描述性 alt、`loading="lazy"` 與 `decoding="async"`。

## 互動與響應式

- 桌面 Header 提供首頁、房型、關於密式與圖集連結，當前路徑用 `aria-current="page"` 標示；行動版選單保留 `#menu-toggle`、`#menu-close`、`#menu` ID 與鍵盤焦點循環。
- 按鈕、導覽連結、社群圖示與 tile 連結的可操作區至少 `44x44px`，所有 focus 狀態清楚可見。
- 版面以 360、390、768、1440px 寬度檢查；手機單欄、平板兩欄、桌面編排保留文字與操作空間。
- `prefers-reduced-motion: reduce` 時停用位移、縮放與淡入效果。JavaScript 關閉時，主要內容、圖片、文字與行動連結仍直接可見，不用透明度隱藏資訊。


## 本版的可見調整

首頁新增由既有營區介紹整理的導讀與「留一晚，靜看山景」照片題字；六張導覽卡增加編號與說明，整張照片卡都可點擊。房型頁從標題到正文統一深藍背景，搭配稍亮的深藍卡片與須知面板，所有價格、須知與規則保持展開。三帳／四帳方案分別顯示適用人數與原價，最低方案在前；沒有方案資料的房型不新增「標準方案」名稱。圖集保留「密式圖集」原標題，新增簡短導讀與經逐張核對的照片替代文字。

資訊頁既有行內紅色提醒不改文字，僅提高與深色背景的對比。頁首與頁尾保留原品牌、訂房及聯絡連結。不得把設計名稱 Dusk Mountain 當作新的公開商家名稱；不得放置暗示不存在輪播功能的頁碼。


## 深色一致性驗收

房型清單、價格區、詳細閱讀區、預訂提醒、須知和相關住宿卡片不得使用米白或白色大底，hover／focus 也不能切成淺色。共用 `global.css` 的背景、面板、文字及強調色 token，不在房型頁另定一套配色。照片保留原色，不以反相或全頁濾鏡實作深色。每次修改須在手機與桌機、作業系統的明亮及深色偏好下檢查實際 computed style，並檢查正文／價格／警告與操作狀態對比。


## 全站介面覆蓋（2026-09-15 補齊）

首頁與房型完成不代表其餘頁面已完成。資訊入口、訂房匯款、園內規約、聯絡方式、菜單、地圖、影片、交通選擇及完整路線彈窗、柑仔店七項服務及彈窗、三項代訂合菜及彈窗、公告列表／文章、404 均須納入桌機與手機驗收。

旅客資訊共用 `GuestNavigation.astro` 與 `guest-pages.css`：桌機使用可辨識的側邊導覽，手機改為可換行連結。卡片需呈現內容或既有價格，不再用一個大空框置中小按鈕。長文使用清楚的閱讀區、段落間距與原生清單；不隱藏或改寫條款。交通與服務彈窗共用深色面板、固定可見的標題及至少 44px 關閉按鈕，路線圖片與說明逐段對齊。

圖片原始菜單或 QR Code 的白底不視為介面淺色面板，不得為配色反相原圖。停用 JavaScript 時以展開內容替代無法操作的彈窗，交通照片仍須可讀。原 SEO、營運段落及每個既有彈窗內文使用建置前後雜湊比對，新的顯示摘要只引用既有來源。

## 逐頁視覺驗收的證據

逐頁開啟與功能測試不能代替看圖。每次整站交付須列出全部正常頁面與 404，各有桌機／手機的完整截圖及視覺檢核紀錄；房型不能只以同模板的代表頁替代。網格須驗證實際欄數與卡片寬度，避免舊欄位類別產生額外隱含欄。

房型輪播以該房型設定的主圖開場，再保留其他原圖；尺寸圖及公告不可因 cover 裁切而遺失文字。選圖按鈕保留小圓點外觀，但可操作範圍至少 44px；控制列不得遮蓋照片，窄螢幕可在列內捲動且目前按鈕應保持可見。退費表格維持原生表格排版，欄位填滿閱讀區，不得留下只有外框延伸的空白。


## 頁面切換與 Header

頁首主要導覽固定為「首頁／房型展示／關於密式／密式圖集」；交通指南仍可從完整選單與關於密式進入，不能把資訊總覽入口直接替換成交通子頁。

Menu 是無常駐外框的文字與雙線圖示按鈕，至少 44px 高；hover 僅改水綠色與線條細節，鍵盤 focus-visible 必須保留明顯指示。展開選單的關閉控制也不加裝飾方框。

頁面切換以操作脈絡決定，不用整頁交疊淡出、上下位移、模糊或縮放掩飾換頁。一般導覽保持 Header 不動，舊頁快照立即移除，新內容僅 140ms 從 0.86 收斂到完整不透明，文字不會雙重曝光；透過導航抵達的整頁卡片不再疊加原本 750ms 的捲動淡入（包含較晚恢復的歷史閱讀位置），hover 回饋保留。

房型列表進入詳情，以及返回可見的原房型卡片，只有同一張房型照片在約 300ms 內延展／收回，使用原生跨文件 View Transition。來源已繪製照片保留在底層，與同一張目標照片交接，避免空框；背景文字不互相交疊。回到列表時僅將那一張已看過的圖片提早載入，其餘照片維持 lazy。若照片不在畫面、未載入、輪播已切到不同照片、資料過期或瀏覽器不支援，直接正常換頁，不等待圖片或強制捲動來演動畫。

保留真實 URL、原生上一頁與閱讀位置；不攔截 click、不 fetch／替換 DOM、不引入 SPA、不延遲任何導航或外部訂房。新增小型 head 腳本只註冊 pageswap／pagereveal 的畫面銜接，單次同分頁暫存僅包含來源／目的路徑與已顯示圖片 URL，不保存使用者資料。JavaScript／暫存受限仍正常換頁。減少動畫明確停用，包括照片延展；首次載入不為特效隱藏正文。

原生規格參考：Chrome Developers「Cross-document view transitions for multi-page applications」及 MDN `@view-transition`（2026-09-15 核對）；支援與否不作為頁面可操作性的前提。


## 現代互動：導航、比較與照片（2026-09-16）

互動不是每個物件都加特效。這次保留深藍與原字型，依旅客動作建立一套可連續操作的流程：

- 完整 Menu 使用編號大字與原圖預覽；hover 或鍵盤焦點改變預覽，未開啟時不載入裝飾照片。一般 Header 的主題底線隨焦點移動，資訊子頁只以 section 標記，不冒用 aria-current=page。底部細線表示實際閱讀進度，不是假載入條。
- 房型分類與詳細頁章節導覽可停留於頁首下方，標示目前內容位置；仍使用真正的頁內錨點，全部條款保持展開。行動版收斂多餘留白，保留房型主圖於第一畫面。
- 房型可加入最多三項比較；加選按鈕是房型連結的兄弟元素，不可嵌入 a。浮動選擇列有移除、清空、兩項起比較的回饋；只在同分頁保存房型 ID，暫存受限時仍可用。比較資料由原內容 collection 產生，每種帳數分別顯示適用人數與平／假／連假原價，不能拿三帳價搭四帳人數。使用者必須能回到完整房型說明，不冒充訂房系統。
- 房型照片可用滑鼠拖動或手指橫向切換，直向動作與雙指縮放保留原生瀏覽器行為。照片旁有實際張數與放大入口。圖集／房型共用完整看圖介面，具備圖說、縮圖列、前後張、放大及滑鼠拖移放大圖。只在開啟後載入可見縮圖，圖片失敗不得把原已讀照片換成壞圖，也不得讓操作永遠等待。
- 選單、比較及看圖開啟時，背景不可操作；關閉後回到原控制並解除捲動鎖。原生上一頁快取及換頁前也清理狀態。照片操作模組共用，不再各頁複製一套焦點或 gesture 實作。

此輪有新增可見操作文字與比較摘要，但沒有改寫原有費用、規則、內容、圖片或字型檔。比較介面只是呈現既有資料，不加入假空房、評價或任何 schema。手勢是原生 Pointer Events 增強；沒有滑鼠游標替換、scroll hijacking、強制自動輪播、遮擋條款的固定訂房橫幅或額外 UI 套件。小幅狀態動效約 140–260ms，減少動畫模式全部停用非必要位移，仍可完成同樣工作。

實作參考：W3C WAI-ARIA APG Dialog (Modal) Pattern、MDN Pointer Events / touch-action / prefers-reduced-motion（本輪核對）。規格只作互動與安全邊界，不作使用者已認同美感的證據。
